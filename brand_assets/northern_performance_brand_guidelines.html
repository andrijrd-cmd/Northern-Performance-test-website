Usage guidelines

Do

  • Use Boreal + Snowfield for hero sections
  • Pair Ember for all primary CTAs
  • Use Sage for supporting UI elements
  • Maintain wide letter-spacing on headings
  • Lead with outcome-driven copy

Don't

  • Mix more than 3 palette colours per section
  • Use light type on Snowfield backgrounds
  • Stretch or distort the wordmark
  • Use clinical stock photography
  • Use playful or rounded typefaces
